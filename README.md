# Scottsdale Together — Christmas 2026

Mobile-friendly itinerary for three families visiting JW Marriott Phoenix Desert Ridge, December 22–28, 2026, with optional December 29–31 suggestions.

## Deployment

This is a static single-page website: no build tools, npm install or API keys required.

1. Create a new repository on your **personal GitHub account** (e.g. `scottsdale-together`).
2. Upload `index.html`, `netlify.toml`, `.gitignore` and `README.md` to the root.
3. In the **existing** Netlify project, go to **Project configuration → Developer settings → Continuous deployment → Repository → Link repository**, then select the GitHub repository.
4. Select `main` as the production branch; leave the build command empty and publish directory as `.`. 
5. Push updates to `main` to redeploy to the same Netlify site URL.

Do not create a new Netlify project if you want to preserve the existing URL.

## Editing

All site content, styling and scripts currently live in `index.html`. This is the simplest setup for a small shareable trip site. GitHub commits track revisions.

### Caveat on sharing edits

This is a static site; editable activity data saved by visitors in their browser does not automatically synchronize across everyone's devices. Commit itinerary changes to the repository to publish the same updated default plan for all visitors. Existing browser-saved edits may override changed defaults, so visitors may need to reset their local plan or open a clean browser.
